Case

Use case inside a match or switch section to define one branch.

TL;DR
  • A case is one branch inside match/switch.
  • It checks one value and runs only when that value matches.
  • Do not use case on its own outside match/switch.
Pattern
case value:
Example
import lib/std.dl

set number to 3

match based on number:
    case 1:
        print "one" as line
    case 3:
        print "three" as line

A case belongs inside a match or switch section. It is not used on its own.

Try yourself

Add a new case for 2. Then change number and run the file again.
