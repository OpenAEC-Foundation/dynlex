If

Use if when a section should run only when a condition is true.

TL;DR
  • Use if for yes/no decisions.
  • Branches are checked top to bottom.
  • The first true branch runs.
Pattern
if condition:
else if condition:
else:

else if and else belong to the same chain as if.

Example
import lib/std.dl

set score to 6

if score > 8:
    print "High score" as a line
else if score > 5:
    print "Nice work" as a line
else:
    print "Keep going" as a line

DynLex checks the branches from top to bottom. The first branch that matches runs.

Try yourself

Change 6 to 9. Then change it to 2.
